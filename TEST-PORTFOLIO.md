\# Test Analyst Portfolio - Noodle Project



\*\*Tester:\*\* Shivani

\*\*Duration:\*\* 15 weeks

\*\*Project:\*\* Noodle Financial Intelligence Platform



\## Executive Summary



This 15‑week QA project validated the Noodle Platform across UI, API, database, performance, security, accessibility, and automation layers. The testing approach included functional testing, regression, cross‑browser checks, SQL/MongoDB validation, Lighthouse performance audits, NVDA accessibility testing, and Selenium automation.



Five critical user journeys were tested end‑to‑end, covering exploration flows, watchlist management, portfolio updates, profile settings, and stablecoin analytics. Integration points between Next.js, Node APIs, .NET services, SQL Server, and MongoDB were thoroughly validated.



Performance optimizations ensured key pages met the <3s load-time target. Regression testing achieved full coverage with evidence. The portfolio includes test plans, user journeys, cross‑browser results, performance reports, security checks, accessibility findings, automation scripts, and complete evidence.



This project demonstrates strong full‑stack QA capability, structured documentation, and professional testing execution.
