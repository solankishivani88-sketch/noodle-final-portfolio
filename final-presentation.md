\# Final Demo Presentation – Noodle Project



\## 1. Project Overview

A noodle platform that helps users explore stablecoins, view analytics, and manage watchlists/portfolios.  

My role was to test the platform end‑to‑end across UI, API, database, and user journeys.



\---



\## 2. Testing Approach

\- Manual functional testing  

\- API testing (Postman)  

\- Database validation (SQL + MongoDB)  

\- Cross‑browser testing  

\- Basic performance checks  

\- Security checks  

\- Regression testing  

\- Accessibility checks (keyboard navigation, focus indicators, NVDA screen reader)

\- Light automation demo (Selenium)



\---



\## 3. Key Findings

\- Core user journeys work smoothly  

\- Watchlist feature correctly updates UI + API + DB  

\- Search and filters return accurate results  

\- Portfolio data loads correctly  

\- No critical security issues found  

\- Performance stable for normal usage



\---



\## 4. Test Coverage

\- UI components tested: 90%  

\- API endpoints tested: 100%  

\- User journeys tested: 100%  

\- Browsers tested: Chrome, Firefox, Edge  

\- Regression checklist: 100% completed



\---



\## 5. Defects Summary

\- \*\*Critical:\*\* Email validation issue  

\- \*\*High:\*\* Profile backend missing  

\- \*\*Medium:\*\* Chart alignment issue in Edge  

\- \*\*Total defects:\*\* 3



\---



\## 6. Automation Demo

\- 15 Selenium C# tests  

\- Covered search, filters, detail page, watchlist    

\- Demonstrated automated regression flow



\---



\## 7. Recommendations

\- Improve profile backend connectivity  

\- Add server‑side validation for profile fields  

\- Enhance accessibility labels  

\- Optimize chart rendering for Edge  

\- Add rate‑limiting for watchlist API
